# Flask JWT CV API

Backend REST API with JWT authentication and admin role,
used to manage a CV profile.

## Features
- JWT authentication
- Role-based access (admin/user)
- Secure password hashing
- SQLite + SQLAlchemy
- Admin-protected CV update
